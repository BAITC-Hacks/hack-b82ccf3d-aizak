# Backend AIZAK — подбор подрядчиков

Автор backend: **Алибек** (ветка `feature/matching`). Контракт для UI и AI-модуля — [CONTRACT.md](CONTRACT.md).

## Пайплайн
```
запрос ─► validate_request ─► город+категория ─► фильтры (дата, бюджет, формат, часы, язык)
                                   │                    │  у каждого отсеянного — коды причин
                                   ▼                    ▼
                              no_category          none_match + suggestions (соседние даты, бюджет)
                                                        │
                   прошедшие ─► ranking.score_profile ─► топ-3 (балл ↓, цена ↑, id ↑)
                                                        │
                   explain.build_facts ─► explainer (AI) ─► grounding.check_explanation
                                                        │ не прошло / нет AI
                                                        ▼
                                              explain_fallback (шаблон из тех же фактов)
```

| модуль | что делает |
|---|---|
| `loader.py` | загрузка CSV/JSONL, валидация и нормализация профилей |
| `matching.py` | фильтры, статусы, причины исключения, воронка `trace`, подсказки `suggestions` |
| `ranking.py` | прозрачный балл из 5 компонент, «почему выше следующего» |
| `explain.py` | факты по карточке: цена, формат, языки, часы, дословные цитаты описания, отличия от соседей |
| `grounding.py` | проверка AI-текста: числа и цитаты только из фактов, без имени и общих фраз |

## Принципы
- **Детерминизм**: одинаковый запрос → одинаковый ответ; AI меняет только текст, не порядок.
- **Ничего не выдумываем**: каждое число и цитата в объяснении есть в данных — проверяется кодом и тестами.
- **Работает без сети**: без AI — шаблонные объяснения из тех же фактов.
- **Честные пустые ответы**: три различимых исхода, причины по каждому кандидату, что изменить в заказе.
- Без внешних зависимостей: только стандартная библиотека Python 3.10+.
